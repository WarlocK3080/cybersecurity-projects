## Network Analysis & Enumeration using Kali Linux

### Objective
To analyze network behavior, identify active connections, and understand how systems communicate within a network using basic enumeration techniques.

---

### Tools Used
- Kali Linux  
- Networking Commands (`ping`, `ip a`, `ss`, `traceroute`, `nslookup`, `arp`, `ip route`)  

---

### What I Did
- Checked network connectivity using `ping`  
- Identified IP addresses and network interfaces using `ip a`  
- Retrieved MAC addresses using `ip link`  
- Analyzed active ports and services using `ss -tulnp`  
- Traced packet path using `traceroute`  
- Performed DNS lookup using `nslookup`  
- Examined ARP table using `arp -a` and `ip neigh`  
- Reviewed routing table using `ip route show`  

---

### Key Findings
- Identified how systems communicate within a local and external network  
- Observed how DNS resolves domain names to IP addresses  
- Understood how open ports and services indicate system activity  
- Learned how routing and ARP tables define network behavior  

---

### Conclusion
This project demonstrates fundamental network analysis techniques used in cybersecurity. It highlights how monitoring network activity and system communication is essential for detecting anomalies and potential security threats.
